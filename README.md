## 💡 Problem Statement  
Financial fraud is evolving rapidly, making it harder for traditional systems to detect it effectively.

**Key Issues:**
- ❌ Delayed fraud detection  
- ❌ High false positives  
- ❌ Inability to detect complex fraud patterns  
- ❌ Regulatory compliance risks  

---

## 🔍 Solution — FraudShield  

An **AI-powered real-time fraud detection system** with built-in compliance verification.

### ⚙️ How It Works  

#### ✅ 1. Compliance Check  
Every transaction is verified against regulatory rules *before* fraud detection.

#### 🤖 2. AI-Powered Fraud Detection  
- **XGBoost, Random Forest, Linear Regression**  
  → Detect anomalies using timestamps & weighted classes  
- **Graph Neural Networks (GNNs)**  
  → Identify complex fraud patterns like circular transactions  

#### 📊 3. Risk Scoring & Alerts  
- Transactions are assigned a **risk score**  
- Flagged cases are sent for admin review  

#### 🧠 4. Contextual Insights (RAG-based)  
- Explain *why* a transaction is suspicious  
- Provide compliance reasoning  
- Help admins make fast decisions
